# Billar Manager - AA4-EV03

Módulo frontend para la gestión de mesas de billar.

## Funcionalidades

- Gestión independiente de tres mesas.
- Activación y desactivación individual del cronómetro.
- Persistencia temporal del estado mediante localStorage.
- Cronómetros independientes por mesa.
- Registro de productos consumibles.
- Cálculo del valor de cada consumo.
- Cálculo del valor del tiempo.
- Cálculo del total a pagar.
- Historial de tiempos anteriores.
- Mesa Común para registrar personas y su cuenta individual de consumo.
- Código comentado y organizado.

## Ejecución

Abrir `index.html` en un navegador web.
